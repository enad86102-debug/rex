هذه مراجعة للكود المنفذ، وليست تدقيق اختراق أو شهادة أمان المنتج النهائي.

## ضوابط منفذة ومختبرة

- رفض الجلسة المفقودة/المزورة/المنتهية/المبطلة؛ الإبطال يستمر بعد restart.
- رفض قراءة/بدء/تعديل طاولة لغير المصرح؛ مالك فقط لمسار البدء المغلق.
- الحد الأقصى أربعة مقاعد حتى عند طلبات الانضمام المتزامنة.
- `action_id` يحفظ إيصالًا، والمدخل المختلف تحت المعرّف نفسه يرفض؛
  `expected_version` يمنع تحديث الجاهزية/المغادرة بناءً على نسخة قديمة.
- عشوائية `crypto/rand` للجلسات والدعوات وshuffle مع rejection sampling؛
  لا `math/rand` أو ترتيب يختاره العميل. فشل entropy يرفض shuffle.
- حفظ بصمات tokens فقط؛ snapshot0600 ومجلد0700، كتابة ذرية، قفل عملية.
- JSON محدود، unknown fields/trailing objects مرفوضة، rate limits محدودة
  الذاكرة، server timeouts، عدم إخراج تفاصيل أخطاء التخزين إلى العميل.
- admin read route غائبة افتراضيًا، بمفتاح منفصل ومقارنة ثابتة الزمن؛
  لا رموز جلسات أو دعوات في البيانات التشغيلية؛ لا admin write endpoints.
- لا request-body logging، ولا hands/purchases موجودة في API أصلًا.
- العميل يرفض HTTP في النهائي ويمنع redirects؛ التخزين المحلي المشفر
  مكتوب، لكن حماية Keystore/backup لم تُتحقق على Android بعد.
- `govulncheck v1.9.0` مع Go1.27.2: لا ثغرات معروفة مكتشفة في النطاق
  المفحوص. لا يفحص Kotlin أو Flutter engine أو Docker OS النهائي تلقائيًا.

## عوائق ومخاطر متبقية للإصدار

1. لا محرك لعبة أو private-hand model: لا يمكن إعلان سرية أيدي الخصوم
   قبل بناء فلترة كل مقعد واختبار payloads/events/replays/logs.
2. snapshot محول مراجعة لا قاعدة إنتاج، له حدود سعة ولا احتفاظ تجاري
   أو HA أو نسخ احتياطي/ترحيل مختبرين على بنية تشغيلية.
3. guest tokens لا تتجدد ولا تُربط بحساب قابل للاستعادة. فقدان الجهاز/
   التطبيق/الجلسة يفقد الوصول؛ UI ينبه، لكنه لا يحل متطلبات الحساب النهائي.
4. إنشاء ضيف ليس idempotent: ضياع أول response قد يترك هوية يتيمة على
   الخادم. لا duplicate money risk حاليًا؛ يلزم معالجة قبل الخدمة العامة.
5. تُنظّف مقاعد انتظار الجلسات المنتهية، لكن سياسة abandonment أثناء
   مباراة فعلية ونظام عقوباتها أو بدائل اللعب لم يُعتمدا بعد.
6. HTTP الداخلي يحتاج TLS edge مع ضبط firewall وtrusted proxy/rate limiting
   مستقل. `REX_BEHIND_TLS_PROXY=true` ليس تشفيرًا بذاته.
7. admin key موحد للقراءة فقط لا يوفر هوية فردية/RBAC أو إدارة بلاغات
   وحظر ودعم/تدقيق العمليات الحساسة. لا إطلاق قبل إكمالها.
8. لا anti-collusion أو attestation أو إجراءات حظر أو moderation؛ لا chat
   أو غرف عامة الآن. لا ادعاء منع الغش مطلقًا.
9. اختبارات Android native على محاكي ناجحة؛ لا اختبار real-device أو
   pipeline ثغرات شاملة لتبعيات Android/Flutter أو فحص مستقل بواسطة مسؤول أمان.
10. snapshot وأحداثه تحتوي معرّفات لاعبين ودعوات: تشفير القرص ونسخ
    الاحتياط والاحتفاظ والحذف والخصوصية تحتاج مراجعة تشغيلية/قانونية.

لا أسرار إنتاج أُنشئت أو أُضيفت إلى Git؛ tokens الاختبارات عشوائية ومحلية
وتبقى خارج المستودع. لا تدّع اكتمال متطلبات الأمان أو الخصوصية من هذه الدفعة.
