# خيارات التنفيذ للمراجعة التقنية — 2026-10-16

هذه خيارات منفذة على فرع معزول بغرض المراجعة، وليست سجل موافقة مؤسسين
أو اعتمادًا نهائيًا من عبدالعزيز. مصدر صلاحية بدء التنفيذ هو توجيه المستخدم
«REX — DEFINITIVE PRODUCTION BUILD DIRECTIVE» في جلسة 2026-10-16.
يتجاوز هذا التوجيه حدود المهام القديمة الخاصة بالتوثيق والواجهات فقط؛ تبقى
حوكمة المشروع وعقود القواعد والمراجعة الفنية سارية.

## الأساس المشترك المنفذ

- Flutter/Dart وGo كما في اتجاه المشروع؛ لا تغيير للمكدس.
- Go modular monolith، بحدود `api` و`service` و`cards` و`cmd/rexd`.
- HTTPS في العميل النهائي، وعدم اتباع التحويلات مع رموز المصادقة.
- REST مع polling كل ثانيتين للطاولات المنتظرة فقط. **ليس قرار نقل أحداث
  المباريات**؛ يتطلب بروتوكول اللعب real-time والتعافي مراجعة منفصلة.
- `action_id` لكل أمر طاولة؛ تكرار المدخل نفسه يعيد الإيصال نفسه، وتغيير
  المدخل تحت المعرّف نفسه يُرفض. `expected_version` لتغييرات العضوية
  والجاهزية. الانضمام متسلسل داخل الخادم لتجنب تعارض حجز المقاعد.
- دعوات عشوائية 128-bit، وجلسات عشوائية 256-bit؛ الخادم يحفظ SHA-256
  للجلسة فقط. الدعوة سرّ قابل للمشاركة بين أعضاء الطاولة؛ ليست هوية حساب.
- guest ID ثابت من الخادم؛ الواجهة تعرض اختصار الهوية الحقيقية، ولا تخترع
  أسماء أو تقدمًا أو نتائج أو أرصدة. لا توجد أسماء مخصصة أو محادثة.
- AES-GCM داخل Android Keystore؛ يحفظ token والطلب المعلّق قبل الإرسال،
  مع استثناء البيانات من النسخ الاحتياطي. لا fallback نصّي.

## محوّل الحفظ الحالي وحدوده

الاختيار: snapshot JSON محلي ذري، بـ0600 للملف و0700 لمجلد البيانات،
sync للملف ثم rename ثم sync للمجلد. قفل نظام تشغيل يمنع تشغيل نسختين
من `rexd` على الملف نفسه. العمليات متسلسلة والذاكرة لا تتقدم عند فشل الكتابة
قبل rename. فشل sync للمجلد بعد rename نتيجة ملتبسة؛ إعادة action ID آمنة.

مبرر محدود: تنفيذ فحوص التعافي والمعاملات باستخدام مكتبة Go القياسية دون
اعتماد مورد أو قاعدة بيانات قبل المراجعة. **لا يُعتمد هذا المحول كقاعدة بيانات
الإنتاج**: لا توسع أفقي، لا معاملات بين العمليات، ولا HA أو نسخ احتياطي
مُدار أو query support. حدوده الصلبة: 10,000 لاعب، 10,000 طاولة،
100,000 إيصال؛ عند بلوغها يرفض طلبات جديدة بدل حذف حماية التكرار بصمت.
آخر 10,000 حدث فقط محفوظة؛ لا تحقق متطلبات الاحتفاظ التجاري بسجلات النزاع.
حجم snapshot وكلفة نسخه وكتابته لم يُقاسا بحمل الإنتاج.

الخطوة المطلوبة من عبدالعزيز: مراجعة اختيار قاعدة بيانات معاملات واحدة
(مثل PostgreSQL أو SQLite لخادم واحد) ومخطط ترحيل/إيصالات/أحداث/نسخ احتياطي.
هذه أمثلة مرشحة، وليست اعتمادًا لأي منهما أو لموفر استضافة.

## سياسات مؤقتة تحتاج مراجعة قبل الخدمة العامة

- جلسة الضيف 30 يومًا بلا تجديد أو ترقية أو استعادة عبر أجهزة. انتهاء الجلسة
  أو مسح التطبيق قد يفقد الهوية؛ ذلك معلن في واجهة الدخول والخروج.
- rate limit محلي: إنشاء ضيوف 5/min/IP، والطلبات الأخرى 180/min/IP؛
  لا ثقة في `X-Forwarded-For`. خلف proxy يحتاج حدًا طرفيًا وقرار trusted
  proxy موثقًا، وإلا تتشارك الأجهزة حد عنوان proxy.
- لا تنظيف لطاولات الضيوف المنقطعين/المنتهية جلساتهم بعد؛ يحتاج سياسة انتظار
  معتمدة منفصلة عن عقوبات الانقطاع أثناء اللعب. لا عقوبات مخترعة.
- لا تجديد تلقائي لرمز الدعوة عند الانضمام؛ يتغير عند المغادرة، ولا يصل الرمز
  الجديد إلى اللاعب المغادر. أي عضو حالي يستطيع مشاركته.
- polling يتوقف في الخلفية؛ عند العودة تُقرأ هوية اللاعب والطاولة من الخادم.
  إعادة الطلب المعلّق صريحة أو عند استعادة العملية. هذا تعافي طاولة، وليس
  تعافي مباراة لا تزال غير منفذة.

## الأدوات المرشحة التي استُخدمت فعليًا

- Go 1.27.2 على Linux؛ `go.mod` يتطلب 1.27.0. الفحص الأمني على 1.27.2.
- Flutter 3.35.7 (`adc901062556672b4138e18a4dc62a4be8f4b3c2`)،
  Dart 3.9.2. SDK مثبت من tag رسمي لأغراض الفحص في هذه البيئة، وليس
  إقرارًا بأنه إصدار الإطلاق النهائي. legacy لم يُغيّر.
- Android compile/target API 36؛ minSdk 23 لتوافق Android Keystore AES-GCM.
- AGP 8.9.1، Kotlin 2.1.0، Gradle 8.12، JDK 21 (bytecode target 17).
  Android لم يُبنَ بعد؛ التوافق الكامل يحتاج فحص بناء فعلي ومراجعة.
- Blender 4.3.2 متاح، واستورد GLB القديم بنجاح للفحص فقط.

## حدود السلامة والإطلاق

لا مشتريات أو عملات أو chat أو bots أو نتائج أو غرف عامة أو matchmaking.
لا endpoints إدارية مفتوحة. توجد قراءة تشغيلية محمية اختيارية
`GET /v1/admin/overview` لتعداد اللاعبين/الجلسات/الطاولات وآخر 50 حدثًا،
بمفتاح منفصل محقون لا يقل عن 32 بايت ومقارنة ثابتة الزمن. تكون route غائبة
إن لم يُضبط المفتاح. لا تظهر الدعوات أو الجلسات أو محتوى أوراق فيها.
مفتاح مشترك للقراءة فقط لا يعوض هويات الإدارة الفردية والصلاحيات؛ التقارير
والحظر والتحقيقات وعمليات الإدارة المدققة لا تزال عوائق إصدار.
`/healthz` يثبت حياة العملية فقط، وليس سلامة كل متطلبات الخدمة.
لا يتضمن الخادم محرك مباراة أو يد لاعب؛ حماية الأيدي يجب اختبارها على
المحرك الفعلي عند تنفيذه، ولا تستنتج من اختبار خصوصية الطاولات.

العميل الحالي أداة تحقق للوظائف المنفذة ضمن مسار إنتاج تدريجي؛ ليس المنتج
النهائي ولا دليل قبول بصري. لا تُنشر هذه الحزمة للجمهور.
