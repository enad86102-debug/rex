# صفقة المقاعد وعقد تركيب المشهد — 2026-10-16

الفرع `production/matchcore-asset-contracts` متراكم فوق PR#4. هذا عمل
هندسي داخلي، وليس بدء مباراة أو تسليم أصول بصرية نهائية.

## ما نُفذ

- `server/internal/matchcore/deal.go`: صفقة من 52 بطاقة فريدة، 13 لكل
  مقعد. يدخل ترتيب الرزمة من خادم اللعبة فقط، أو يستخدم خلط CSPRNG الموجود
  في `cards`. تُنسخ بيانات الإدخال، وتُرفض الرزم الناقصة أو المكررة أو
  ذات رتبة/صنف غير صالح.
- `SeatView` يحتوي يد المقعد فقط وأعداد أوراق الثلاثة الآخرين. نسخة اليد
  المخصصة لمحرك القواعد لا تعدل الحالة الداخلية. لا endpoint يستعمل
  الصفقة بعد؛ بدء المباراة يبقى مقفلًا بـ`rules_not_approved`.
- `assets/scene-contract.json`: عقد تركيب مرشح للمراجعة لأربعة مقاعد،
  سطح ورق مستقل، ست سمات طاولة، وأربع بيئات. جميع النماذج غير موجودة
  و`release_approved=false`. الألوان والأبعاد مقترحات هندسية وليست
  موافقات فنية أو كتالوجًا مدفوعًا.
- فاحص Python يرفض غياب أي مقعد أو سمة/بيئة، إدخال بطاقات أو أسماء في
  خامات الطاولة، ووسم نموذج غير مراجع بأنه معتمد.

## التحقق

- `go test -race -cover ./...` و`go vet ./...`: ناجحان. تغطية
  `matchcore` هي 92.9%، و`cards` 100%، و`api` 92.0%، و`service` 84.4%.
  اختبارات الحزمة تتحقق من انعدام تسرب أوراق الخصوم في JSON لكل مقعد،
  وعدم وجود alias لليد أو الرزمة، وصحة الخلط/التوزيع ورفض الإدخال الفاسد.
- `python3 -m unittest discover -s production/tools -p 'test_*.py'`:
  11 اختبارًا؛ 6 نجحت و5 اختبارات process متخطاة دون binary، وتُشغل
  فعليًا عبر `check_live.sh`.
- `check_live.sh`: خمس تجارب process لخادم compiled binary ناجحة، ثم
  اختبار Flutter بأربع اتصالات مستقلة إلى الخادم الفعلي ناجح.
- `check_security.sh`: gosec بلا findings أو analysis errors؛ Staticcheck
  وgovulncheck بلا نتائج معلنة، وGitleaks بلا أسرار مكتشفة.
- CI تضاف نتيجته بعد انتهائه، دون افتراض نجاح.

## ما ينقص

لا يوجد turn legality أو trick/sequence engine أو مزايدة أو تسجيل أو
نتيجة أو مباراة حية؛ تختلف القواعد الإقليمية، ويتطلب تشغيلها عقدًا
معتمدًا لكل لعبة. لا يوجد model طاولة أو كرسي أو بيئة أو إنسان إنتاجي؛
لا تكفي الألوان والـanchors لإطلاق مشهد. لا تبنى scene في Flutter قبل
مراجعة عبدالعزيز للـrenderer وقياس الأجهزة ومراجعة الفن وحقوقه.

الاعتماد التالي المحدد: عقد Trix Complex أو Tarneeb بإصدار وأمثلة
نتائج معتمدة، ثم تطوير module اللعبة وربطه باسترداد حالة مباراة خادمية؛
وبالتوازي تسليم نماذج GLB بمصادر تحرير وحقوق ومراجعة بشرية كي تُملأ
خانات المشهد بلا placeholders.
