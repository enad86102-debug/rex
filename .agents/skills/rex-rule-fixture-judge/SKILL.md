# rex-rule-fixture-judge

## Scope
Create human-reviewable boundary fixtures from an approved Trix or Tarneeb rules edition.

## Work procedure
1. Start from exact contract version and approval record; refuse unsourced regional defaults.
2. Build small canonical hands or trick/sequence examples with expected legal moves.
3. Include queen of diamonds combined penalties, king hearts, pass, double, redeal and tie decisions.
4. Have independent rules expert verify expected output before encoding fixtures.
5. Use candidate profiles for research but keep public /start gated until formal approval.

## Sources to consult, not auto-execute
- [go-fuzz](https://go.dev/doc/security/fuzz/) — research reference, not a runtime dependency
- [agent-skills-spec](https://agentskills.io/specification) — research reference, not a runtime dependency

## Evidence contract
Report actual source SHA, inspected paths and lines, exact tests (or NOT_RUN), security implications, reviewer dissent, and one of PASS / REQUEST_CHANGES / BLOCK. The tool or external skill must not be claimed installed unless actually verified in the active environment. Approval classes D2/D3 remain human-gated.
