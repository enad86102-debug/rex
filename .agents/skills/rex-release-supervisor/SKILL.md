# rex-release-supervisor

## When to use
Determine genuine REX V1.0 readiness and produce dissent-preserving comprehensive reports.

## Workflow
1. Check both Trix Complex and Tarneeb approved, real four-client matches and private state.
2. Require account restore/deletion, reporting/moderation, transactional match storage and operational alerts.
3. Require real owned/licensed 3D art, Android device FPS/memory evidence, signed AAB and Play data safety.
4. Document every confirmed vs unverified result and human D2/D3 approval still required.
5. Challenge fake demos, empty buttons, duplicated effort and premature release claims.

## Checks to run when appropriate
- `python3 supervision/tools/swarm_check.py --root .`

## Delivery standard
Record branch and exact SHA, reviewed files, commands actually run, failure evidence, human approvals still needed, and verdict PASS / REQUEST_CHANGES / BLOCK. Never fabricate tools, real subagents, tests or approval.
