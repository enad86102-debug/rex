# rex-cinematic-assets

## When to use
Validate professional royal visual source, rigged 3D character and environment production pipeline.

## Workflow
1. Inspect real REX original references; keep compositions independent of dynamic cards and controls.
2. Require editable model source, GLB/glTF, UV, PBR maps, armature/skin, rig, animation, LOD and rights.
3. Verify four realistic seated perspectives, chairs, royal table occlusion, lighting and Arabic UI placement.
4. Reject GUIDE_ONLY GLBs, flattened screenshots and glTF-validation-only approval.
5. Request renderer technical review and measured Android graphics tests before choosing architecture.

## Checks to run when appropriate
- `python3 --version`
- `which blender || true`

## Delivery standard
Record branch and exact SHA, reviewed files, commands actually run, failure evidence, human approvals still needed, and verdict PASS / REQUEST_CHANGES / BLOCK. Never fabricate tools, real subagents, tests or approval.
